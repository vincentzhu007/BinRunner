Claude Code explained that `libGL.so.1` is not needed by the phone app itself — it's a build-time dependency of the **hvigor build tool**. The `CompileResource` step uses `libimage_transcoder_shared.so` to process image resources during compilation, and that shared library links against desktop OpenGL. This has nothing to do with the final HAP — it's purely a quirk of Huawei's build toolchain. The fix (installing `libgl1-mesa-glx` in the Docker SDK image) is the quickest workaround.
